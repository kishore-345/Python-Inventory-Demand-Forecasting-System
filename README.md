# Python-Inventory-Demand-Forecasting-System
Inventory management system using Python and NumPy with demand forecasting.

## Project Overview
This project is a simple inventory management system built using Python and NumPy. It helps track product details and forecast future demand based on historical sales data.

---

## Business Problem
The objective of this project is to help businesses manage inventory efficiently by predicting future demand and avoiding stock shortages or overstock situations.

---

## Features
- Product management (name, price, stock)
- Sales data input
- Demand forecasting using moving average
- Calculation of average demand
- Demand volatility analysis
- Reorder decision logic

---

## Technologies Used
- Python
- NumPy

---

## Project Structure
- Product class for handling product details
- DemandForecaster class for demand analysis
- Uses NumPy for calculations like mean and standard deviation

---

## Key Functionalities
- Calculates average demand
- Measures demand volatility using standard deviation
- Forecasts next month's demand using moving average
- Suggests reorder quantity based on forecast

---

## Sample Output
- Displays product details
- Shows demand analysis results
- Indicates whether reorder is required

---

## Conclusion
This system helps businesses make better inventory decisions by analyzing past sales data and predicting future demand.
